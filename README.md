
# Plantsy

Plantsy is a React application for managing plants in a plant shop.

## Features

- Display plants from the backend.
- Add new plants using a form.
- Mark plants as out of stock.
- Search for plants by name.

## Technologies

- React
- JavaScript
- CSS
- JSON Server
- Vite
- Vitest

## Installation

npm install

## Running the Application

Start the backend:

npm run server

Start the frontend:

npm run dev

## Testing

npm run test
